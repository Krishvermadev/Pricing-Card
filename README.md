
# Pricing Page

A modern pricing page created using HTML and CSS. This project showcases a clean and professional user interface with three pricing plans, a dark-themed layout, custom pricing cards, and a monthly/yearly toggle design.

## Features

- Modern dark-themed design
- Responsive card-based layout
- Interactive pricing toggle UI
- Three pricing plans (Free, Efficient, Team)
- Clean typography and spacing
- Hover-ready buttons and components
- Built entirely with HTML and CSS

## Technologies Used

- HTML5
- CSS3

## What I Learned

- CSS Flexbox and layout design
- Card component styling
- Box shadows and border radius
- Responsive design concepts
- UI/UX design fundamentals
- Structuring reusable components

## Preview

A clean SaaS-inspired pricing section featuring colorful pricing cards and intuitive navigation.
